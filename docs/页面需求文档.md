# mdairy 页面需求文档

> 依据 [开发文档](./开发文档.md) §1 产品定义与 §4 MVP 功能清单（F1–F13）编写。
> 本文是 UI 实施的唯一依据；功能行为以开发文档为准，本文只管"长什么样、怎么交互、怎么验收"。
> 设计系统由 ui-ux-pro-max 生成（Minimalism & Swiss，variance 2 / motion 2 / density 5），针对桌面编辑器场景做了适配，偏差处已注明理由。

## 1. 设计系统

### 1.1 风格

- **Minimalism & Swiss**：干净、留白、功能至上、高对比、几何、无装饰。避免：过度装饰、复杂阴影、3D 效果、emoji 当图标。
- 图标一律用 **Lucide** SVG（`lucide-react`），线宽 1.5–2px，尺寸 16px（行内）/ 18px（按钮）。
- 动效克制：所有过渡 150–250ms ease-out；只动 opacity/transform；尊重 `prefers-reduced-motion`。
- 所有可点元素：`cursor: pointer` + hover 态 + 可见焦点环（键盘可达）。

### 1.2 色彩 token（CSS 变量，亮/暗各一组）

亮色（暖石色系 + amber 点缀，长文编辑不刺眼）：

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FAFAF9` | 窗口/编辑区背景 |
| `--bg-sidebar` | `#F5F5F4` | 侧栏 |
| `--bg-inset` | `#F5F5F4` | 代码块、输入框底 |
| `--fg` | `#1C1917` | 正文 |
| `--fg-muted` | `#57534E` | 次要文字（对比度 ≥ 7:1） |
| `--border` | `#E7E5E4` | 分割线、描边 |
| `--accent` | `#D97706` | 主操作、选中态、链接 |
| `--accent-fg` | `#FFFFFF` | accent 上的文字 |
| `--danger` | `#DC2626` | 删除、错误 |
| `--ring` | `#D97706` | 键盘焦点环 |

暗色（保持暖调一致；accent 提亮保证对比度）：

| Token | 值 |
|---|---|
| `--bg` | `#0C0A09` |
| `--bg-sidebar` | `#171412` |
| `--bg-inset` | `#1C1917` |
| `--fg` | `#FAFAF9` |
| `--fg-muted` | `#A8A29E` |
| `--border` | `#292524` |
| `--accent` | `#F59E0B` |
| `--accent-fg` | `#0C0A09` |
| `--danger` | `#EF4444` |
| `--ring` | `#F59E0B` |

主题三态：跟随系统 / 亮 / 暗（F10），切换立即生效，持久化到本地设置；入口两处——macOS 顶部菜单栏 **主题** 菜单（跟随系统/浅色/深色，勾选态双向同步）与状态栏三态循环按钮。

### 1.3 字体

**离线原则：不从 CDN 加载任何字体，全部用系统字体栈**（对 ui-ux-pro-max 推荐的 Inter 的调整——Tauri 应用离线可用优先）。

- UI 与正文：`-apple-system, "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif`；正文 15–16px，行高 1.6；UI 辅助文字最小 12px。
- 编辑器：同上 sans 栈；代码块/行内代码：`"SF Mono", Menlo, Consolas, monospace`，13–14px。
- 渲染预览的标题层级：h1 28px / h2 22px / h3 18px / h4–h6 16px，均 `font-weight: 600`。

### 1.4 布局规范

- 间距基准 4px，常用 4/8/12/16/24。
- 窗口默认 **1280×800**，最小 **960×600**。
- 侧栏（260px）承载**文件 / 搜索 / 大纲**三种视图；视图选择与显隐都在 macOS 菜单栏 **Sidebar** 菜单（勾选单选，全部不勾 = 隐藏边栏；再点当前勾选项 = 隐藏）；⌘⇧O 为键盘切换入口。

## 2. 界面清单与信息架构

单窗口应用，"页面"即窗口内的面板与弹层：

| 编号 | 界面 | 类型 | 覆盖功能点 |
|---|---|---|---|
| W1 | 主窗口（三区布局） | 常驻 | F1 F2 F3 F4 F6 F8 F9 F12 |
| W2 | 命令面板 | 弹层 | F11 |
| W3 | 全文搜索面板 | 侧栏页签 | F7 |
| W4 | 外部修改冲突对话框 | 模态 | F5 |
| W5 | 文件操作对话框（新建/重命名/删除确认） | 模态/内联 | F2 |
| W6 | 空状态 | 常驻占位 | F1 |

## 3. 界面详细需求

### W1 主窗口（三区布局）

```
┌────────────────────────────────────────────────────────────────────┐
│ Sidebar                    │ TabBar: ●笔记A  笔记B  ＋     [编辑|分栏|预览] │
│ ┌────────┬───────────────┐ │─────────────────────────┬──────────────────│
│ │ 文件/搜索 │  VAULT 名     │ │                         │ Outline          │
│ │ 页签切换  │  ▾ 日记/      │ │  EditorPane (CM6)       │ (可折叠 220px)    │
│ │          │    2026-10.md │ │  或                     │  # 标题一         │
│ │ ▾ 日记/  │  ▸ 工作/      │ │  Editor | Preview 分栏  │  ## 小节          │
│ │ ▸ 工作/  │  笔记B.md     │ │  或 PreviewPane         │                   │
│ │ 笔记B.md │               │ │                         │                   │
│ │          │               │ │                         │                   │
│ │          │               │ │─────────────────────────┴──────────────────│
│ │ [底部:    ]               │ │ StatusBar: 路径 · 字数 · 保存状态 · 主题按钮  │
└────────────────────────────────────────────────────────────────────┘
```

#### W1-S 侧栏（宽 260px，视图由菜单栏 Sidebar 控制）

- 视图三选一：**文件** / **搜索**（即 W3，⌘⇧F 切过去）/ **大纲**（即 W1-O）；窗口内无页签行，选择入口在 macOS 菜单栏 **Sidebar** 菜单；全部不勾 = 收起整个侧栏。
- 文件页签 = 文件树（F2）：
  - 展示当前 vault 的目录结构，文件夹可展开/折叠（状态记住），md 文件显示文件名（不含 `.md` 后缀，设置项可改回全名）。
  - 点击文件 → 在新标签页打开（已打开则聚焦该标签）。
  - hover 行尾出现 `⋯` 菜单：新建文件 / 新建文件夹 / 重命名 / 删除；文件夹行还支持在其下新建。
  - 空白区右键：新建文件 / 新建文件夹 / 在 Finder 中显示。
  - 隐藏非 md 文件与 `_assets/`（图片仍可通过链接访问）。
- 侧栏顶部显示 vault 名（文件夹名），点击可**重新选择文件夹**（F1）。

#### W1-T 标签栏（TabBar，F6）

- 标签项：文件名 + 关闭按钮 `×`；**有未保存修改时 `×` 变为圆点 `●`**，点击弹确认（保存/放弃/取消）。
- `+` 按钮新建空文件；中键点击标签 = 关闭。
- 标签可点、可拖拽排序**后置**（本期不做，仅点选）。
- 右侧固定放**三态视图切换**（F9）：分段控件 `编辑 | 分栏 | 预览`，默认分栏；快捷键 ⌘E 循环切换；全局记忆（不随标签变）。

#### W1-E 编辑区（F4）与预览区（F3）

- **纯编辑**：CM6 占满主区；markdown 语法高亮；⌘S 保存，保存成功后状态栏短暂提示"已保存"，无 toast 打断。
- **分栏**：左编辑右预览，各 50%，中间 1px 分隔线；**滚动同步**——以编辑器光标所在块为锚点，预览滚动到对应块（标题/段落级映射，允许 ±1 块误差）。
- **纯预览**：PreviewPane 占满，居中最大宽度 760px，左右留白。
- 预览渲染（F3）：markdown-it 管线——GFM 表格/删除线/任务列表（可勾选但**不回写文件**，勾选交互本期禁用）、highlight.js 代码高亮、KaTeX 行内/块级公式、Mermaid（懒加载，渲染失败显示原始代码块 + 错误行提示）、链接 `http(s)` 用系统浏览器打开、`wikilink` 本期按普通文本渲染。
- **图片粘贴**（F12）：编辑器内粘贴图片 → 写入 `vault/_assets/`（文件名 `YYYYMMDD-HHmmss.png`）→ 光标处插入 `![](_assets/xxx.png)`；粘贴时状态栏提示"图片已保存"。预览中以 vault 根为基准解析相对路径。
- 编辑器防抖 300ms 触发预览重渲染；预览 DOM 一律过 DOMPurify。

#### W1-O 大纲（侧栏"大纲"页签）

- 列出当前文件 h1–h3（h4 缩进可选显示），按层级缩进；点击 → 编辑器光标跳转到该标题并滚动可见。
- 当前光标所在章节在列表中高亮（跟随滚动）；无标题时显示"暂无标题"占位。

#### W1-B 状态栏（高 28px）

- 左：当前文件相对 vault 的完整路径（超长省略中间）。
- 中：字数（中文字符 + 英文单词数）。
- 右：保存状态（`已保存` / `未保存`）、主题切换按钮（三态循环：系统/亮/暗，图标随状态）。

### W2 命令面板（F11，⌘⇧P）

```
┌──────────────────────────────────┐
│ 🔍 输入命令或文件名…        esc    │
├──────────────────────────────────┤
│ 命令                              │
│  ▸ 打开文件夹…            ⌘O     │
│  ▸ 切换主题：亮色                 │
│  ▸ 视图：分栏                     │
│ 文件                              │
│  ▸ 日记/2026-10-03.md            │
│  ▸ 笔记B.md                      │
└──────────────────────────────────┘
```

- 居中偏上（距顶 15%）模态浮层，宽 560px，遮罩点击关闭，`esc` 关闭。
- 输入框自动聚焦，模糊匹配（连续子串即可，不引入重量级 fuzzy 库）。
- 结果分组：**命令**（打开文件夹、切换三态视图、切换主题、新建文件、全局搜索、折叠/展开侧栏等全部命令）/ **文件**（vault 内按修改时间近优先，最多 20 条）。
- ↑↓ 选择，↵ 执行，⌘↵ 在新标签打开文件；选中项右侧显示其快捷键。
- 命令是唯一注册点：新增功能命令只需注册到命令注册表（实施约定）。

### W3 全文搜索面板（F7，⌘⇧F）

- 侧栏切换到"搜索"页签：顶部输入框 + 命中数（"12 个文件，34 处"）。
- 结果按文件分组：文件名 → 逐条命中行（命中词 `<mark>` 用 accent 10% 透明度背景高亮，每文件默认展开前 5 条，可展开全部）。
- 点击命中行 → 打开该文件并**选中第一个命中词**（编辑态）；纯预览态则切换到编辑态再定位。
- 输入防抖 250ms；**搜索范围为当前活动文件所在文件夹（含其子目录）**，未打开文件（未命名缓冲区）时退回全库；摘要行显示实际范围（"范围 日记/2026/ · 12 处" / "范围 全库"）；切换到其他文件夹的文件自动按新范围重搜。排除 `_assets/`；大小写不敏感。
- 空 vault / 无结果分别显示占位文案（见 §4）。

### W4 外部修改冲突对话框（F5）

- 触发：正在编辑的文件被外部程序修改或删除（watcher 事件 + 保存时比对 mtime 双保险）。
- 模态对话框，不可点遮罩关闭（必须三选一）：
  - 标题：`文件已在编辑器外被修改`
  - 正文：显示文件名 + 两个时间（你的修改时间 / 磁盘上的修改时间）。
  - 按钮：**从磁盘重新加载**（丢弃内存修改，危险操作用次要样式但放在左侧主位）/ **保留我的版本**（下次 ⌘S 直接覆盖磁盘）/ **取消**（暂不处理，标签保持脏状态）。
- 文件被外部删除：同对话框，选项变为"在编辑器中保留（保存时重建文件）"/"关闭标签"。
- 焦点管理：打开时焦点落在安全项（取消），tab 可在三个按钮间移动。

### W5 文件操作（F2）

- **新建文件/文件夹**：在文件树目标位置内联输入行（非模态），默认名 `未命名.md` / `新建文件夹`，回车确认、esc 取消、失焦=取消；重名时输入行红框 + 行内提示"已存在同名文件"。
- **重命名**：文件树节点原位变为输入框，规则同上；重命名后：若该文件已打开，标签与路径同步更新。
- **删除**：确认对话框——`删除 "xxx"？此操作将移入废纸篓。`（macOS 用 trash API，不直接 rm）；按钮：删除（danger 样式）/ 取消；删除已打开的文件后自动关其标签。
- 所有操作失败（权限/IO）toast 报错，文件树回滚到操作前。

### W6 空状态

| 场景 | 展示 |
|---|---|
| 启动（无论有无上次工作区） | 自动打开一个 **未命名** 缓冲区标签（Typora 式，不落盘）；编辑区无占位文字（对标 Typora 空白编辑区）。⌘S 弹系统保存对话框（默认 vault 根 / `未命名.md`；无 vault 时先选文件夹再保存，vault 内转正为真实标签，vault 外落盘后关闭标签） |
| 无上次工作区 | 侧栏显示引导：Lucide `folder-open` 图标（48px，muted 色）+ 文案"打开一个文件夹，开始笔记" + 主按钮 `选择文件夹…`（⌘O 同效）；主区仍是未命名缓冲区可写 |
| vault 存在但无任何 md | 文件树显示"空文件夹" |
| 搜索无结果 | "没有找到与 "xx" 匹配的内容" |
| 文件加载失败 | 主区错误态：图标 + 原因 + `重试` 按钮 |

## 4. 通用反馈规范

- **Toast**：右上角，3s 自动消失，最多叠 3 条；仅用于非阻断反馈（保存失败、图片已保存、操作出错）；成功/错误用图标区分，不用颜色 alone（无障碍）。
- **Loading**：本地 IO 极快，不设全局 loading；仅大文件夹首次建索引时侧栏文件树显示骨架屏（3 行灰条）。
- **危险操作**一律 danger 色按钮 + 确认；其余操作即时生效可撤销的（如关闭空标签）不确认。

## 5. 全局快捷键

| 快捷键 | 动作 |
|---|---|
| ⌘O | 打开文件夹 |
| ⌘N | 新建笔记 |
| ⌘S | 保存当前标签 |
| ⌘W | 关闭当前标签（脏时确认） |
| ⌘E | 循环切换 编辑→分栏→预览 |
| ⌘B | （预留）折叠/展开侧栏 |
| ⌘⇧O | 切换侧栏显隐 |
| ⌘⇧P | 命令面板 |
| ⌘⇧F | 全文搜索 |
| ⌘P | 快速打开文件（命令面板的文件模式） |

macOS 用 ⌘，Windows/Linux 对应 Ctrl（本期仅 macOS 落地，注册时用平台抽象）。

## 6. 验收清单（交付前逐项过）

- [ ] 所有图标为 Lucide SVG，无 emoji 图标
- [ ] 亮/暗两套主题下正文对比度均 ≥ 4.5:1（含 muted 文字）
- [ ] 纯键盘可完成：开文件、编辑、保存、搜索、切视图、切主题、关标签（无键盘陷阱，tab 顺序与视觉一致，焦点环可见）
- [ ] 所有交互反馈 150–250ms 过渡，`prefers-reduced-motion` 下无动画
- [ ] ⌘S / ⌘⇧P / ⌘⇧F / ⌘E 在编辑器聚焦时也生效（不被 CM6 吞掉）
- [ ] 三态切换、侧栏/大纲折叠、主题选择均持久化，重启后恢复
- [ ] 长文件名、长路径、超长代码行均正确省略/换行，无横向滚动条溢出窗口
- [ ] 全部 UI 文案为中文、无英文占位残留
